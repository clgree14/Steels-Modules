Manual Installation: I have included a folder containing the module files. After extracting the files folder just right click on your foundry application in your taskbar and select browse user data then navigate to the modules folder, and inside there you need to place the whole folder of the module you are copying. From there the module should appear in you modules list to activate.

To manually install a module on The Forge (when you have a .zip archive or lack a standard manifest URL), use The Forge's built-in Summon Import Wizard rather than dragging and dropping files into a local computer folder.

Step-by-Step Installation Guide

1. Log in to The Forge: Open your web browser, go to The Forge website, and log into your account.
2. Open Game Configuration: Navigate to your My Foundry dashboard and select the Games Configuration tab.
3. Launch the Import Wizard: Click on the Summon Import Wizard button (found under the table tools or top-left menu).
4. Select the ZIP File: Choose the ZIP file option from the import prompt and browse your computer to select the downloaded module .zip archive.
5. Analyze and Import:
	• Click Upload and wait for the file to transfer.
	• Click Analyze Files so The Forge scans the package.
	• Click Import All (or choose to import it directly as a module). The wizard will unpack it and place the content into your Assets Library or module directory.
6. Restart Your Server: Stop and then start your The Forge server instance so it recognizes the newly uploaded package.
7. Activate in Your World:
	• Launch your game world inside The Forge.
	• Open Game Settings and click Manage Modules.
	• Check the box next to your newly installed module and click Save Module Settings.
