I have included a folder containing the module files. After extracting the files folder just right click on your foundry application in your taskbar and select browse user data
then navigate to the modules folder, and inside there you need to place the whole folder called nels-combat-exploits. From there the module should appear in you modules list to activate.

Alternatively, you can follow the following process:
Access Add-on Modules: Open your Foundry VTT setup page in a web browser and navigate to the "Add-on Modules" tab.
Initiate Installation: Click the "Install Module" button.
Provide Manifest URL: In the pop-up window, paste the Manifest URL of the module into the "Manifest URL" field. You can find this URL on the module's distribution page 
Install: Click "Install." Foundry VTT will then download and install the module.
Enable in World: Launch your game world, go to "Game Settings" (gear icon), click "Manage Modules," and enable the newly installed module by checking its box. Click "Update Modules" at the bottom to save.
